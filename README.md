♻️ EcoLoop (Symbiosis)
AI-Driven Waste-to-Resource Matching Platform

Symbiosis is a web-based platform designed to connect waste providers and waste receivers through intelligent AI-based matching. The platform promotes sustainable waste management by converting reusable waste into valuable resources, supporting the principles of a circular economy.

Users can register as either a waste provider or a waste receiver, communicate securely within the application, and complete transactions using UPI intent-based payments. The system also displays location and distance information to enable efficient coordination.
